# labs

Maven-мультимодуль с кодом лабораторных работ.

## Сборка

```bash
cd labs
mvn clean install
```

Требуется JDK 21.

## Модули

- `common` — конфигурация подключения, модель события, JSON serde
- `lab03-producer` — режимы отправки, кастомный partitioner
- `lab04-consumer` — ручной коммит, rebalance listener, lag-репортер
- `lab06-transactions` — read-process-write с EOS
- `lab07-admin` — диагностика кластера
- `lab12-streams` — оконная агрегация с тестами

## Как добавить свой модуль

1. Создайте каталог `labNN-название` с таким же `pom.xml`, как у соседей.
2. Добавьте `<module>` в `labs/pom.xml`.
3. Добавьте цель в корневой `Makefile`.

## Заметки по коду

Классы намеренно написаны в один файл на сценарий и без фреймворков: цель —
видеть работу клиента Kafka напрямую, а не абстракцию Spring Kafka поверх неё.
Когда механика станет понятной, перепишите те же сценарии на Spring Kafka
и сравните, что фреймворк делает за вас и какие настройки он скрывает.
